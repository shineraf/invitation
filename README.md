# Froi & Jam — Emerald & Gold Wedding Invitation

A reusable, mobile-first luxury wedding e-invitation for GitHub Pages.

## Theme
Deep emerald green, antique gold, warm ivory and champagne with editorial serif typography, gold-framed photography and responsive luxury styling.

## Sample photography
The template uses sample photographs hosted by Unsplash through `images.unsplash.com`. Replace the sample URLs in `weddingConfig.gallery` inside `script.js` with your own licensed photos before publishing a final invitation.

## Customize
Edit `weddingConfig` in `script.js` to change names, date, venues, map URLs, photos, music, RSVP endpoint and quote.

## GitHub Pages
Deploy directly from the desired branch/root in Settings → Pages. All local assets use relative paths.

## RSVP
Static GitHub Pages cannot securely store submissions. Set `weddingConfig.rsvp.endpoint` to a compatible hosted form endpoint.
